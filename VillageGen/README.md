# VillageGen

A self-contained browser version of the medieval fantasy city generator,
configured to open with the requested preset:

- size 25
- seed 1429458196
- citadel, plaza, temple, walls, and river enabled
- urban castle, shantytown, coast, and greens disabled
- automatic gates

Open `index.html` directly or serve this directory with any static web server.
The `size` and `seed` query parameters are supported, and **new city** creates a
fresh random city.

This is the repository's GPL-3.0 reimplementation of Oleg Dolya's
[Medieval Fantasy City Generator](https://watabou.github.io/city-generator/),
not a copy of the original site's compiled application or analytics.
